Brain Tumor Detection Using MRI Images

Final Year Project

Developed a system for the detection and classification of brain tumors using MRI images, bridging the gap between medical imaging and computer science.

Key Responsibilities & Features

  • Built the front-end interface using Flask to allow users to upload and analyze MRI scans.
  • Implemented image detection and classification algorithms optimized for medical imaging data.
  • Managed testing and training processes using structured databases to improve detection accuracy.

Technologies Used

  • Python
  • Flask
  • Machine Learning (Image Classification)
  • OpenCV / Imaging Libraries
